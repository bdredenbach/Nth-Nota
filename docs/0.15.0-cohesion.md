# Nth Nota 0.15.0 — a more connected desk

This update refines existing tools and the paths between them.

- Shared tool names and icons distinguish structured widgets on the canvas and in Saved notes.
- Desk search recognizes common jobs and synonyms, with up to four recently used tools. Categories still start expanded; manual collapses and search remain available.
- Connected items links notes, plans, documents and widgets across canvases. Manual links work both ways. Existing relationships from created tasks, remembered dates, mind maps and reference notes appear automatically.
- Work with this writing groups the writing companion, Snippet Shelf and Make it a task. Task creation reviews the selected passage or active field and preserves the original. A task retains a path back to its source.
- Saving state is visible in editor headers. A device save failure offers retry and backup actions, and close confirmations follow completion of the save. Backgrounding and page transitions capture the active draft before flushing pending changes.

Connections are stored as bounded item identifiers, without copying a linked item's content. Trash hides connected items until restored; missing or permanently removed items do not produce broken navigation. Backups preserve manual links and recent tools. Removing a connection keeps both items and does not remove relationships created by another tool.

A save conflict from another open window continues to require backup or reload; Retry does not overwrite that window's changes. A browser process terminated before storage finishes can still lose its latest changes, so backups remain useful. The app does not claim a save succeeded after a reported storage failure.

Validation covers search language, recent-tool ordering, bidirectional and automatic relationships, trash restoration, connection limits and backup validation. Browser checks exercise selected text becoming a task, navigation between connected items, cross-canvas links, persistence after reload, injected device-write failure and retry, and a draft captured at pagehide. These run in Chromium and WebKit alongside the existing PWA, widget and Android tests. Physical-device testing remains with the testers.
