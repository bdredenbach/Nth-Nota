# Nth Nota 0.9.0 — four ways to develop a thought

All four modes are saved as ordinary note records with additional structured data. Each keeps a text representation for search, text export and optional Writing companion context. Existing notes, window controls, backups, workspace deletion and consent are preserved. No cloud AI is required to use these modes.

## Photo to text

Choose an existing JPG, PNG or WebP photo through the system picker. This release does not open a camera or request camera permission. The original image stays inside the note; a JPEG working copy, normalized and rotated on device, is limited to 2048 pixels on its longest edge. Printed Latin-script text is read through the bundled Google ML Kit Text Recognition model (16.0.1), with no model download or photo upload. Other writing systems and handwritten-photo accuracy are not claimed.

Review the extracted text beside the source. Text blocks can be selected individually or through their source-image boxes. Replacing the draft with selected blocks is an explicit action. Re-extraction and rotation preserve existing edits; rotation clears obsolete block coordinates. Export text uses the normal note exporter; Export original photo preserves the source file. Stop and closing detach late results without erasing the source or text. Native image transfers are length checked and limited to 6 MiB after preparation. Recognizers and bitmaps are released after inference finishes, including cancellation.

## Daily journal

The journal opens one page per local calendar date and workspace. Choosing another date opens that page without changing the current page’s date or creating duplicates. Morning, evening and free-writing sections coexist in one record. Mood is optional and there is no score or streak. One small step can become a linked task; opening that task again preserves subsequent edits rather than recreating or overwriting it. No notification is enabled automatically.

## Mind map

Connected thoughts have a label, details and a named relationship to their parent. Move nodes by their grips or arrow keys; arrange branches automatically, use Overview to fit the map, review a text outline, and undo/redo map edits. Removing a branch shows a confirmation and includes its descendants. Notes and tasks already promoted from that branch remain. Open as note and Make it a task retain the source map and reopen an existing linked item when available. Maps are bounded to 60 thoughts; backup validation rejects cycles, duplicate identifiers and missing parents. Layout keeps deep trees inside portable coordinate bounds.

## Math sheet

A deterministic arithmetic sheet gives each value a short name, label, expression and optional unit label. Formulas may reference other lines, including forward references. Show working reveals substituted values. What if compares alternate inputs while keeping originals; changes propagate through dependent formulas. Supported operations are +, -, multiplication, division, powers, percentages, parentheses, scientific notation, pi and e. Units are labels, not automatic dimensional conversion. Missing/duplicate names, cycles, invalid expressions and non-finite answers remain visible as line errors. No eval, code execution or AI-generated arithmetic is used. Sheets are bounded to 50 lines with 180-character expressions.

## Integration and limits

Desk adds Photo to text, Daily journal, Mind map and Math sheet. Each has contextual first-visit tips and the standard save/minimize/close controls. New data is validated in backups. Journal and math input handlers use input events, including Android keyboard insertions. Writing companion receives the saved text, not original photos or a second hidden data channel, and follows existing local-first/cloud-opt-in behavior.

The bundled privacy policy and `cloud/worker.mjs` privacy HTML include photo processing and these local note types. The gateway’s writing/report endpoints, credentials, quotas and provider choices are unchanged. Redeploy the Worker to refresh its public privacy page; extraction does not depend on that redeployment.

Actual OCR accuracy on the phone, interrupted-device lifecycle behavior and performance across physical Android devices remain manual test items. Browser inference fixtures validate UI/transfer/cancellation but do not run ML Kit. 84 JavaScript/database checks, 45 browser checks and 16 native unit tests passed. The signed build completed successfully, all 45 bundled editor files match the checkout, and the signing certificate matches earlier preview APKs. Results are recorded in `android-build-status-0.9.0.json`. The previous AI retry check now waits for actual idle state instead of assuming a fixed 30 ms delay.
