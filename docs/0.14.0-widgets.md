# Nth Nota 0.14.0 — a playful corner of the desk

Desk → **Miscellaneous** contains Fidget Spinner and Dice Tray. This category starts expanded, alongside the five existing categories. Both tools create ordinary saved canvas items: they can move between workspaces, minimize, close to Saved notes, restore, appear in List view and travel in backups. Their controls work on the canvas and in their editor.

## Fidget Spinner

Choose Classic, Flower, Ninja Star, Round, Hazard or Orbit. Each is drawn as scalable artwork with a shaded surface, highlight and center bearing. Six palettes and a custom color picker change the finish. Tap or press Spin, flick or drag the shape, and press Stop whenever you want. Keyboard users can activate Spin and Stop normally.

Angular velocity decays over time. Animation frames run only while spinning, stop on backgrounding, and are canceled when their widget is removed or its editor closes. A spinner always opens at rest. Reduced motion limits the speed and shortens the spin. Shape and color persist; transient motion does not write to storage every frame.

## Dice Tray

Choose d4, d6, d8, d10, d12, d20 and d100 quantities. **Classic seven** selects one of each; **Clear selection** starts a new pool. d100 is a single percentile result from 1 to 100. The limit is 20 of each type, up to 50 dice total.

Roll animates all selected dice, then shows each value, its type and the total. The editor keeps the last 20 rolls. Dice share the six palettes and custom color control, with faceted artwork and highlights. Reduced motion shows the outcome promptly without tumbling.

Results use Web Crypto random integers with rejection sampling, avoiding modulo bias. Each result is generated once and saved before the animation begins. Repeated taps cannot queue rolls during the animation. Closing, reloading or backgrounding during a roll retains that exact outcome. Pool changes do not alter previous rolls.

## Validation

Model tests cover all seven ranges, rejected overflow random draws, quantity limits, sums, invalid restored results, palettes, geometry and backup round trips. The shared mobile browser checks cover actual spinner flicks, keyboard control, background cleanup, all shapes, custom colors, mixed pools, disabled duplicate rolls, interrupted animation, reduced motion, reloads and reopening. These run in Chromium for the Android web bundle and in Chromium and WebKit for the PWA.

The release pipeline also runs the existing application, offline-browser and native Android checks, builds the APK with the existing preview identity, verifies its signature, and publishes it only after matching web checks pass. Physical Android and iPhone interaction testing remains a tester task.

Full live and practice tours remain disabled. Short first-visit tool tips include the two new widgets.
