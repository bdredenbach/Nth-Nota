# Nth Nota 0.8.1 — Android calculator input

The recording showed valid equations such as `12 + 12 =`, `2*2=` and `2 / 2 =`
remaining unanswered on Gboard. The note editor previously depended on an `=`
keydown event, which Android IME text entry may omit.

Automatic math now handles inserted text and completed composition, using the
actual paragraph/line at the caret. It keeps the existing arithmetic parser,
respects the Automatic math setting, preserves formatting and other paragraphs,
and saves the result with the note. It does not evaluate pasted prose or rerun
calculations during undo/redo. Invalid equations remain editable without a result.

Usage: enable Settings → Automatic math, open a text note, type a numeric equation
on its own line, then type `=`. For example, `12 + 12 =` becomes `12 + 12 = 24`.
Use `*` or `×` to multiply and `/` or `÷` to divide. This is available in text-note
writing areas, not note titles or the drawing canvas.

Browser checks cover text insertion without any equals keydown, a physical
equals key, IME composition, paragraph/BR boundaries, formatted text, persistence,
the opt-out, paste, invalid arithmetic and undo. Actual Gboard behavior is the
next phone confirmation. No Cloudflare Worker update is needed.
