# Feedback refinements — 0.13.8

Full walkthroughs are paused behind `FULL_TOURS_ENABLED` in `dist/tutorial.js`. The live Desk tour and the practice tutor both refuse to start while this flag is false, including direct API calls. The implementations, scenes and existing full-walkthrough checks are retained. Launch controls in Desk, Settings and contextual tips are hidden. First launch shows optional permission choices directly.

The short contextual tips remain independent of the full-tour flag. They appear on first entry to each tool when Tips as I explore is enabled. Closing a tip records that area as seen, keeps tips enabled for other areas and does not open the permissions screen. Settings opt-outs persist as before.

All five Desk categories begin expanded on a fresh load. Manual collapses remain in effect for that session. Searching temporarily opens matching categories; clearing search returns to the user's chosen category states.

Verification covers disabled full-tour entry points, original editor preservation, first-visit tips, closing and reopening areas, opt-out persistence, all default-expanded categories, collapse/search behavior, fresh installs and existing onboarding markers. The shared browser checks run in Chromium and WebKit. The Android workflow checks the browser UI, native tests and APK signature, and publishes the APK only after the matching web checks pass.
