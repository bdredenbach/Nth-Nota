# Nth Nota 0.7.1 — an Nth Experience tour

The tutorial now spotlights actual app controls, following FootPrints' first-visit
tour pattern. A six-stop desk tour opens the real bottom-up Desk menu and points
out workspaces, note creation, the saved/minimized dock and the writing companion.
It does not create demo notes or change a user's notes or permissions.

After the desk tour, independent permission choices remain optional. Skip,
the tour's Close button, Escape and Android Back review those choices. Skipping
also disables further automatic tips until they are enabled again in Settings.

Short first-visit tours appear in the note, drawing/image/PDF, tasks, task-alert,
voice, assistant, saved-notes, settings and backup screens. Each has Back, Next
and a final action returning to the actual tool. The voice and task tips offer
explicit microphone and notification requests. The assistant tip opens the full
cloud disclosure and resumes the same tip after acceptance or decline. No tour
action starts recording, creates an alert, downloads a model or sends an AI
message. Tips do not interrupt an active recording or reply.

Settings includes Tips as I explore and Replay tutorial. Seen tips and the
enabled choice live on this device, outside backups and cloud consent. Upgrading
from the old information-card tutorial introduces the new desk tour once.

The spotlight and coach card follow the app theme and reposition on scrolling,
rotation and visual-viewport changes. Native HTML dialog focus containment keeps
the underlying app out of the keyboard focus order while a tip is open. The real
tool becomes interactive again when its tips finish.

Validation includes the existing JavaScript/database checks and Chromium checks
for tour navigation, real menu visibility, note preservation, first-visit/replay
behavior, opt-ins without feature activation, cloud consent decline/acceptance,
Android Back/Escape, and phone/landscape layouts across the four themes. Native
permission prompts and keyboard behavior still need confirmation on the phone.

This is an APK/web-shell change. The already deployed Cloudflare Worker does not
need another deployment for the tour.
