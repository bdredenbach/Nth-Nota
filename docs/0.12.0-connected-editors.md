# Nth Nota 0.12.0 — connected editors

- Newly created and restored items reveal themselves with a short canvas/list scroll and a highlight. Reduced motion uses an immediate scroll and static outline. Saved notes and Trash restoration use the same non-overlapping placement rules. Restored items append in List view. Moving an editor to another canvas uses the same placement helper.
- Writing Companion has an editor destination. Select a writing field, review a reply, and replace or add text there. Opening the companion keeps the original editor, draft, structured state, and callbacks available. A selected note passage can be replaced without replacing its surrounding writing. Task rows keep completion and notification state. Drawing/image/PDF editors have an editable caption. Future editors using the shared item shell inherit the integration. Save as separate note remains an explicit choice. Context refresh is required if background conversion changes a field while the companion is open.
- Handwriting Auto waits 950 ms between completed strokes, recognizes a snapshot, and adds its words to the same note. New strokes can continue during recognition; only recognized strokes are consumed. Alternatives can replace the last automatic reading. Undo last words restores that batch and returns to manual mode. Errors preserve ink and turn Auto off. Auto preference survives backups. Handwriting still uses on-device recognition; Writing Companion retains existing local/cloud consent behavior.
- Reminders supports creating a new reminder directly as a canvas note, or attaching a schedule to an existing item. Canceling a new reminder creates nothing. Persistent notifications independently pin an existing item without a scheduled reminder. Stop removes only the notice. Task notices retain Complete; generic pinned items offer Stop showing and reopen their source item. Existing schedules and source contents are preserved.
- Desk Menu tools are grouped under Write & capture, Think & create, Plan & remember, Numbers & budgets, and Workspace & help. Borderless expandable categories use keyboard-accessible controls. Search reveals matching tools across categories.
