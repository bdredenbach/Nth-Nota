# Nth Nota 0.13.0 — more tools for your desk

Android preview version code 25. Existing saved items and Reference Lab remain compatible.

## New Desk tools

| Tool | Category | Behavior |
| --- | --- | --- |
| Scanner | Think & create | “Turn paper into pages”. Android document scanning with gallery import, cropping and cleanup; a picture import path with rotation, edge trimming, paper appearance, ordering, PDF export, first-page preview and document notes. |
| Index Builder | Think & create | “Custom rulebooks and game data”. Tabs with their own fields, reference entries, links between entries, and text/tag filters across one tab or the whole index. |
| Snippet Shelf | Write & capture | “Reusable blocks and boilerplate”. Store text, code and Markdown; insert a block into the active writing field or selected passage using the shared Snippet Shelf button. Literal code and markup remain text. |
| Streak Board | Plan & remember | “Daily consistency tracker”. Multiple routines, daily amounts, 52-week heat maps, current/best streaks, daily targets and total goals. Progress bars stop at 100% while actual totals stay visible. |
| Flash Cards | Plan & remember | “Small cards. Lasting knowledge”. Front/back editing, tags and search, shuffled study by tag, answer reveal and self-rating. Decks and unfinished study sessions are saved locally. |

All five tools save as canvas items, participate in search and backup/restore, and use the shared editor and canvas destination controls. Index Builder is separate from Reference Lab.

## Screenshot refinements

- Writing Companion has a second **Send this writing** button beside the current writing context, with an ornamental **or** divider above the custom message. It preserves any custom message already being drafted. Replies can still replace or add to the selected writing in the original editor.
- The Reminders hub's **Create persistent notification** action uses the primary button color. The reminder composer also has this action and the shared Writing Companion/Snippet Shelf controls. A new persistent notification saves the entered text as a canvas item without requiring a date or creating a scheduled reminder. Existing item schedules are preserved.
- Writing fields in item editors receive the shared controls through the modal infrastructure, including structured tools, audio/transcription, handwriting, drawings and documents. Settings dialogs that only choose dates, permissions or existing items do not need writing assistance.
- Explicit dates in writing offer **Remember** suggestions. English month names/abbreviations, ordinal days and ISO dates are supported. Yearless dates use the calendar's displayed year or the current year for other editors; that year is shown in the suggestion. A suggestion adds an event only when chosen. The calendar's existing month widget then shows a dot and the selected date's event details. Reopening an already remembered suggestion does not duplicate the event.

## Scanner behavior

The Android path uses Google's ML Kit document scanner, provided through Google Play services. First use may download scanner components; availability depends on the phone. If it is unavailable, picture import still works. The native scanner owns its camera UI. Scanned PDF contents are received locally by Nth Nota; they are not sent to Writing Companion. Document notes use the normal text assistance controls.

The picture path stores resized JPEG source pages and the generated PDF. Rotating, trimming, changing appearance, reordering or removing pictures rebuilds the PDF. The Android scan result is a completed PDF; replace it with a new scan or picture import to change its source pages. A replacement is applied only after a valid new PDF is ready. Cancellation and late native callbacks preserve the saved document. Failed picture rebuilds retain the editable picture draft and prevent export of a stale PDF until rebuilt.

Each document supports 20 pages and a 12 MiB generated PDF. Scanner transfer messages are matched to a single request, bounded by declared byte count, and discarded after cancellation. All imported tool structures are validated before backup restore.

## Validation

The release workflow runs JavaScript syntax, model and storage recovery tests; Chromium desktop/mobile UI checks; Android unit tests; APK assembly; and APK signature verification. The added checks exercise linked-entry deletion, escaped reusable content, cursor insertion, date suggestions and duplicate prevention, routine logs, study sessions, real picture-to-PDF output and native scan transfer/cancellation fixtures.

Automated scanner fixtures do not test a physical camera, document edge recognition, or the Play services first-use download on a handset. Those require a phone check with the installed APK.
