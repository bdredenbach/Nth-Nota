# Nth Nota 0.13.6 — tour actions stay in place

Android preview version code 31.

The Desk search highlight follows the actual search field during the menu’s opening animation and when filtering changes the menu height. When the menu closes, the search highlight clears and the tutor points to Desk with an Open Desk action. Reopening resumes the same interaction and retains the typed search. Close, scrim, Desk toggle and Escape use the same recovery behavior.

The shared target tracker checks geometry before paint while either tutor is open, then stops when it closes. It only repositions after geometry changes. Hidden, inert, disconnected, transparent or clipped targets cannot leave a marker at an old location. Markers stay within the visible part of their target. Automatic panel placement leaves the marked interaction point free; a manually moved panel retains its chosen location.

Closing an editor while practicing offers a return to the current instruction. Pop-up choices can be finished or canceled before resuming. Back, chapter changes and return-to-step preserve writing entered before Next. Drawing replay retains separate strokes and their pointer events. The tutor remains reachable with Tab while the editor or Desk menu is open. Its header and navigation buttons stay visible while the explanation scrolls, including on Safari drawing screens.

Both browser engines exercise all 25 chapters using real control clicks, typing, selections and drawing. Additional checks cover a slowed menu animation frame by frame, filtering, repeated close/reopen detours, unfinished drafts, closed editors, modal choices, hidden and inert controls, scrolling and keyboard access. Chromium also checks the entire tour with reduced motion. Existing source-editor restoration, service boundaries, offline use and saved-note checks remain in place. These automated checks do not replace physical phone testing.
