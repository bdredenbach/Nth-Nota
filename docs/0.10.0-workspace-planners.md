# Nth Nota 0.10.0 — a desk for plans

## Workspaces and saving

Tap the icon beside the workspace title to choose from 22 symbols or edit its name and description. New and existing workspaces retain their symbol in backups. Existing desks keep familiar default symbols.

Every saved editor has a Canvas picker: text, tasks, drawings, image/PDF markup, audio/transcripts, handwriting, photo text, journals, mind maps, math sheets, budgets, and calendars. The recorder has its own destination picker before the audio note is created. Moving a dated journal refuses a destination that already contains a live page for the same date. Notes retain their content and reminder metadata; a moved floating card is placed near the destination canvas origin. Restoring or opening a note brings it above overlapping cards without moving the other notes. Window order is saved and survives restart and backup restoration.

The editor’s × and Android Back save and return the item open on its chosen canvas. Minimize still uses the dock. The × on a canvas card still puts it away in Saved notes. Pressing the recorder’s × stops an active recording and saves captured audio once; a pending microphone permission request without captured audio still closes safely.

## Budget planner

A local note with a period, currency, income and expense categories, planned/actual amounts, a protected set-aside amount, category spending bars, and remaining totals. Arithmetic uses integer cents, with explicit validation and paused totals when an amount is incomplete. Blank amounts count as zero. Up to 80 categories; up to two decimal places. Seven currencies are available; changing the currency relabels values, without an exchange conversion. No bank connection or financial account access.

## Calendar

A month grid with a selected-day agenda, optional entry times, editable dates/details, keyboard navigation, leap-day support, and month/today controls. Up to 300 entries in a calendar note, dates from 1900 through 2199. Entries autosave. Make it a task links to a task without automatically scheduling a notification; its bell controls optional alerts. Opening the same linked task does not create a duplicate. Journal for this day uses the calendar note’s chosen workspace and opens/reuses that day’s page. No external calendar sync or calendar permission.

Both planners have canvas previews, plain-text mirrors for search/export and selected AI context, and first-use guided tips. Backup validation preserves structured data and rejects malformed structures. Cloud AI consent is unchanged, and no Worker update is required.
