# Nth Nota 0.7.0 coordinated pass

## Included

- Saving a voice recording returns to the canvas and reveals its open audio card.
- Creation tools live in note/media editors. The Desk menu retains every creation
  route; Workspace view contains canvas/list, zoom, and compare controls.
- Image transforms and pen strokes share a bounded undo/redo history. The two
  history buttons stay together. Original imported attachments are preserved.
- A six-step tutorial can be replayed. Skip, Close, and Android Back lead to
  independent permission choices. No skip action accepts consent.
- Cloud AI is off until an explicit current consent choice. Legacy default-on
  preferences are not accepted as consent. Local inference remains automatic.
- A first cloud fallback can ask for consent without losing the conversation.
- Every task has an optional timed reminder and optional ongoing notification.
  Native Complete, Stop showing and user dismissal reconcile with the desk.
  Deleted/completed tasks and notices explicitly stopped by the user do not continue to show unwanted notices.
- Privacy & data includes the bundled policy, backup, local data deletion, saved
  report status, and permission choices. Reports contain only reviewed excerpts
  and user-entered details, with separate explicit submission consent.
- Prompt guidance asks for clarification when a planning goal is missing and
  keeps suggestions within the app's writing/planning purpose.
- Device support information, system font scaling, flexible editor controls,
  locale-aware dates and speech defaults, and basic RTL layout support are added.

## Cloudflare rollout required separately

The APK can be tested without a gateway change: existing writing requests remain
compatible. Receiving reports and enforcing the new report retention requires
deploying `cloud/worker.mjs` to the existing Cloudflare Worker. That deployment
also serves the bundled privacy policy publicly at `/privacy`.

1. Replace the Worker code with `cloud/worker.mjs` and deploy. Keep the existing
   AI, DB, IP_HASH_SALT, FREE_ONLY_CONFIRMED, and optional Groq bindings/secrets.
2. The report endpoint creates its report table if missing. The equivalent
   migration is `cloud/migrations/0002_ai_reports.sql`.
3. Configure the daily cron trigger `7 0 * * *` (UTC), as in the Wrangler example.
   It deletes quota entries older than two days and reports older than 30 days.
4. Send an explicitly consented test report in-app, confirm Sent, and inspect
   D1 `ai_reports`. Never label a pending local report as received.
5. Review reports through the restricted Cloudflare dashboard; use them to
   improve generation safeguards. Do not expose the report table publicly.

No API secrets belong in the APK. The shared daily cloud allowance remains 50
attempts, with a 15-attempt daily connection/IP cap. This remains a limited free
preview, not an unlimited public service.

## Public release gates still requiring external/device verification

- After deploying the Worker, verify its public `/privacy` URL and use that URL
  in Play Console. The Worker serves the same policy as `dist/privacy.html`;
  the APK already includes the policy text. Live hosting is not yet verified.
- Confirm actual Cloudflare/Groq account logging, retention controls and terms.
- Complete Data safety against those facts. Cloud text is off-device collection;
  ordinary voice recording/transcription is local. Explicit reports are optional
  off-device excerpts. Assess service-provider sharing exceptions separately.
- Verify live report delivery and daily cleanup after gateway deployment.
- Evaluate real-model ambiguity and safety behavior on local and cloud engines.
  Prompt instructions and mocked UI replies are not proof of response quality.
- Physically test notifications (including reboot/dismiss/complete), accessibility
  at 200% text, additional manufacturers, tablets/foldables, and older Android.
  Browser fixtures validate UI flows, not Android OS delivery or device support.
- Full UI translation is not implemented. Basic RTL and system locale handling
  are a foundation, not a claim of completed localization.
- Verify the new audio-saving interaction on the phone. Recording worked in the
  user's 0.6.0 test; real transcription quality still needs device confirmation.
