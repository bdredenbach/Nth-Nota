# Nth Nota 0.11.0 — room for different ways to think

## Workspace and creation

- Calendar cards can switch between an agenda preview and an interactive month grid. Select a day on the canvas, move between months, or open that day in the full planner.
- Newly created items follow the previous open card to its right in Canvas view. At the horizontal boundary they start a new row. In List view they append below existing open items. Existing positions are preserved.
- Title bars have a visible three-line grip; the whole bar remains draggable. List view hides the grip because cards are not freely draggable there.
- New note creation buttons are consolidated into Desk. Editor ribbons open Desk in place of the former Type creation button. Workspace creation and content controls such as Add task or Add branch remain available.
- Canvas destination pickers include Create new canvas. A nested dialog keeps the editor and any recording alive, supports cancellation, and selects the new destination without discarding the draft.

## Guidance

Math Sheet has a six-step, hands-on guide for expressions, names, dependent lines, what-if values, and inspecting substituted values. Its guide button can reopen it without re-enabling unrelated tips. Contextual Math guidance permits editing the real controls. Hide explanation compacts a tour without closing the tool. Spotlight scrolling and available-space limits keep the highlighted Math working clear of the explanation. The first-run tour keeps its separate permission choices and focus containment.

## Calculator

A keypad, editable expression field, keyboard Enter/=, bounded recent history, and a Math box using the existing automatic equals solver. Arithmetic uses the safe expression parser; it never evaluates JavaScript. Percent is arithmetic division by 100. Keep this calculation creates a separate note containing the expression and answer. The calculator note also keeps its own history and Math box.

## Reminders

A local hub for note reminders, timed task alerts, persistent task notices, and optional Time Capsule alerts. Filter by canvas or kind, edit/open the source, stop an alert, or complete a task. Stopping alerts preserves the original note or task. Labels reflect saved settings, not proof of delivery. Android permission, channel, scheduling and dismissal behavior remains in the existing native notification implementation.

## Time Capsule

Notes for your future self. Start a letter, record a message, draw something, or select a saved note/recording/sketch. Seal it until a future local date and time, with optional notification. Six-month and annual shortcuts clamp month-end and leap-day dates. Each alert revision is independent of its reveal time, so a previous Stop does not suppress a newly enabled alert at the same time.

This is a scheduled reveal based on the device clock, not encryption or secure storage. The UI explicitly discloses readable backups and an Open early path requiring typing OPEN. Sealed contents are hidden from canvas previews, ordinary search, comparison and direct writing-assistant/transcription entry points. Titles remain visible. Existing note reminders are preserved, with their body hidden while sealed. Capsule alerts use the existing native task-notification path and source-item deep link. Source content, strokes, audio and transcripts stay in the original item.

Event detection, external calendar integration and encrypted locking are not included. The reveal requires no cloud service.

## Choice Weaver

Weigh choices. Find clarity. Each option keeps pros and cons. Weighted view supports 2–8 options, 1–8 criteria, integer weights from 0–10, ratings from 1–5, and an explicit higher/lower preference. Scores normalize against active weights and display the working. Missing ratings or invalid weights pause rankings; zero-weight criteria are ignored; ties are shown. Results describe the user’s entered priorities, not an objective decision. Wide tables retain the option-name column while scrolling.

## Reference Lab

Your personal cheat sheet. Up to 120 searchable reference cards with tags, free detail, up to eight custom fields, card/table views, and up to eight related-reference links per card. A reference can create and reopen a linked ordinary note. Removing a reference prunes related links and preserves separately created notes. Structured values, links and selected entries survive backups; the text mirror supports search, export and selected AI context.
