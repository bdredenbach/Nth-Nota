# Nth Nota 0.13.1 — watch it, then try it

Android preview version code 26. The tutorial adds an automated walkthrough alongside the existing contextual tips.

## How to use it

Open **Tutorial**, then **Watch the tour**. The walkthrough opens the real tools, types example text, uses their actual buttons and shows the result. A chapter picker jumps to any of 25 areas. **Play/Pause**, **Back/Next**, three pace choices, and **Try it** let people watch or practice. Reduced-motion preferences make demonstrations immediate rather than animating typing and strokes.

When a tool's contextual tips are open, **Show me** starts its own chapter. Exiting the walkthrough returns to the original screen, including an open draft or an unfinished companion question. Finishing an introductory walkthrough still leads to the existing optional permission choices.

## Examples

- Write a note and return it to the canvas; add and check a task.
- Review a clearly labeled prepared companion reply, then apply it in the same note.
- Draw real pen strokes, undo/redo them, and see where reviewed handwriting words go.
- Update named Math sheet values and a what-if, calculate an expression, and change a budget total.
- Remember a date and see its dot in the canvas calendar.
- Create a persistent message as a practice canvas item without scheduling a real alert.
- Build linked index entries, insert a reusable snippet into a note, log a routine, and reveal/rate a flash card.
- Import a prepared picture through Scanner's real image-to-PDF path and rotate/clean the resulting page.
- Review prepared photo text and explore the existing saved music sample without opening a microphone.

## Keeping the user's work in place

Before entering, the current draft is flushed and saved. The original editor DOM, callbacks, state, view, focus and scroll context are retained while demonstrations use a temporary practice state. Practice writes are blocked at the save, queue and storage-write boundaries. Native notification synchronization and service mutations are suspended for the practice session. Exit restores the original state and editor; practice items are discarded. Closing the app during a tour leaves the already saved original desk intact.

Active recordings, replies, recognition, scan preparation and document loading must finish before a practice session starts. The walkthrough does not request permissions, start a recording, send an AI request, open a device scanner, export a file or replace a backup. Such actions remain available with the user's own work after leaving the tour. The companion example is explicitly labeled as prepared. User input pauses automatic playback; hiding the app pauses it too. Escape and Android Back exit the practice session.
